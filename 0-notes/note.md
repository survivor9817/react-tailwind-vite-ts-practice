۵. onFocusPageNumber با useRef — رفتار درستی داره، ولی یه edge case رو چک کن

اگه کاربر focus کنه، input رو خالی کنه، بعد بدون تغییر دیگه‌ای همون کتاب رو ببنده و کتاب دیگه‌ای باز کنه (که currentPage رو از بیرون عوض می‌کنه)، onFocusPageNumber.current هنوز مقدار قدیمی رو نگه داشته و اگه بعد از اون blur اتفاق بیفته، ممکنه صفحه رو به یه مقدار غلط برگردونه. احتمالاً edge case نادریه ولی ارزش تست دستی داره.
